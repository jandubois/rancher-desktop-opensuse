### Skill improvements

- When a PR body uses a closing keyword (`Fixes`, `Closes`, `Resolves`) on an issue with several requests, check each request against the diff, and flag a closing reference to an issue the PR only partly addresses, because the merge closes it and the deferred part leaves the open list.
- When a workflow triggers on `workflow_run` (or `pull_request_target`), the PR's CI ran the default branch's copy of that file, so state that the change is unexecuted and read any "passing" run's `headSha` before citing it as evidence.
